# TextureManager

Плагин для Minecraft-сервера, который позволяет заменять стандартные текстуры через простую папку `textures`.

## Основная идея

Администратор просто помещает PNG-файлы в соответствующие папки внутри `plugins/TextureManager/textures/`. Плагин проверяет изображения, собирает ресурс-пакет Minecraft, создаёт SHA-1 и автоматически отправляет актуальный пакет игрокам.

## Планируемые возможности

- автоматическое определение версии Minecraft;
- автоматическое определение подходящего формата ресурс-пака;
- поддержка любых разумных разрешений PNG без жёсткого ограничения 16×16, 32×32, 64×64 и т. д.;
- проверка повреждённых PNG;
- автоматическая сборка ресурс-пака;
- SHA-1 хеш готового ресурс-пака;
- автоматическая отправка после входа игрока;
- горячая перезагрузка без перезапуска сервера;
- резервные копии предыдущих сборок;
- русские сообщения и конфигурация;
- права администратора;
- хранение исходных текстур непосредственно в папке плагина.

## Простая структура текстур

```text
plugins/
└── TextureManager/
    ├── config.yml
    ├── textures/
    │   ├── block/
    │   ├── item/
    │   ├── entity/
    │   ├── gui/
    │   └── particle/
    └── resourcepack/
```

Например:

```text
textures/block/stone.png
textures/item/diamond_sword.png
textures/entity/cow/cow.png
```

Плагин сам преобразует эти файлы в структуру Minecraft `assets/minecraft/textures/...` при сборке ресурс-пака.

## Русская локализация

Все сообщения, описания настроек и служебные уведомления для администратора по умолчанию предоставляются на русском языке. Названия команд и permission-узлы остаются на английском для совместимости с серверными системами прав.
